# CarePath

CarePath is an AI-assisted healthcare navigation prototype designed to guide users toward appropriate care pathways based on self-reported symptoms.

This project is a research-oriented prototype and is not intended for clinical diagnosis or treatment.

## Version
v1.0.0 — Core symptom triage and care pathway guidance

## Scope (v1.0)
- Symptom-based input
- Possible condition suggestions
- Urgency level indication
- Recommended specialist categories
- Care pathway overview
- Accessibility-focused, minimal interface
- Multilingual support

## Design Focus
CarePath is intentionally designed with elderly usability in mind, emphasizing simplicity, low cognitive load, and clear step-by-step navigation. Japan’s aging population was used as a reference context for accessibility-driven design decisions.

## Limitations
- Non-diagnostic
- No medication or dosage recommendations
- Not a substitute for professional medical advice

## Status
Frozen baseline prototype. Further development continues in subsequent versions.
